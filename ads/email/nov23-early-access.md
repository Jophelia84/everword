## Making the discount work
A single Shopify discount code can't change its percentage with the number of items, so pick one:

1. **Simplest (recommended):** turn on the three tiered automatic discounts on Nov 23 instead of Nov 26. If your admin offers customer eligibility on automatic discounts, limit them to the `bf-early-access` segment. If it doesn't, leaving them open for three days is fine, because nothing public announces the sale until Nov 26. No code means no friction at checkout.
2. **Code only for subscribers:** install a tiered-discount app (Shopify Functions based) so one code, e.g. `LIST`, gives 20/25/30%. Add "Use code LIST at checkout" under the button.
